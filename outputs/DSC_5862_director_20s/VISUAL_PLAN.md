# DSC_5862 视觉编排表（导演视角 · 20s 风格序列版 v2）

这一版不再用"一镜到底真人 + 信息卡"，改成**五个已拆解风格连续接力**，
画面出现方式每一段都不同：全屏 → 黑底竖版画中画 → 全屏跟随花字 → 黑底圆形场景 → 产品特写加主播圆窗。

## 全片检查

1. **画面是否帮助理解**：五段各只解释一类信息（香调 / 性格场合 / 第二支香调 / 使用场景 / 试香方法），没有装饰镜头。
2. **连续重复、节奏单一**：五段画面形态全不相同（全屏 / 黑底矩形 / 全屏花字 / 黑底圆形 / 特写加圆窗），
   真人出现方式分别是全屏、缩小画中画、全屏、圆形画中画、右下圆窗，不再是一镜到底的单一出现方式。
3. **变化太少或信息过载**：每段都有 3-4 次内部变化，且变化时刻压在口播字级时间码上。
4. **未核实素材**：未使用任何未经提供的画面；文字只使用口播原文，没有编造卖点或数据。
5. **重点强调**：「更饱满」「都接得住」「琥珀感更深」「可以重点试闻」「再判断」五处结论各有独立视觉落点。
6. **前后连贯**：S002→S003→S004 三次硬切都落在语义段落边界；S003 花字坐标继承 S001，S005 圆窗继承 S004 的圆形语言。
7. **需补素材 / 需确认**：见下节。

## 需确认

1. **产品名**：实物瓶身核对为阿玛尼红挚爱 Sì Passione 与 TOM FORD 珍华乌木 Oud Wood，沿用上一版结论。
2. **12.5-13.5s 一句**：ASR 字面是「琥珀感更加的深」，语义不完整，本版按可读性写作「琥珀感更深」。
3. **S005 裁切**：产品特写裁到托盘与手部，主动切掉脸部，靠右下圆窗保留主播表情；这是该风格的正统用法。
   圆窗必须用独立预裁的 `assets/face-closeup.mp4`（520x520），窗口与素材 1:1 对应（`left:0; top:0; width:304px; height:304px`）。
   如果直接复用主画面源，圆窗会在推近时跟着一起放大，且旧版按全幅 1920x1080 算出的偏移值会让圆窗只剩画面一角。

## 需补充素材

1. **真正的产品特写 / 瓶身微距**：现在是把托盘镜头上裁 1.64 倍，画质到顶就是这个水平；
   有真瓶身微距或喷头细节，S005 可以直接换素材、不用裁切。
2. **香调原料空镜**：黑加仑、柠檬、玫瑰、茉莉、乌木、檀香、琥珀七个香调目前只能用文字表达，
   没有原料或气味氛围镜头可切。

## 制作难度较高

1. **预热一帧**：overlay 在浏览器里合成真人画面，每次渲染的第一张截图图层会滞后一帧，必须先丢弃一张预热。
2. **画面系统切换**：五段窗位由 `body[data-shot]` 控制，必须靠时间轴在 5.22 / 8.85 / 13.56 / 16.75 四个点上切换，
   漏一个点就会退回到"一镜到底"。
3. **S005 推近**：推近只作用在 `#wA video` 上，用 transform 的 `scale` 而不是 `left/top/width/height` 补间
   （按像素补间会在慢速推近时产生整数跳变），并且必须 `immediateRender:false`，
   否则 GSAP 会在建时间轴时就把放大值写成内联样式，把前面四段全部顶掉。
4. **HyperFrames 校验**：本版 overlay 已用 HyperFrames CLI 跑过官方检查，
   `hyperframes lint` 为 0 errors / 0 warnings，`hyperframes inspect --samples 20` 为 0 layout issues。
   中文字体（等线，约 15.6MB）超过 HyperFrames 的 2MB 内联上限，因此成片仍走自研 HTML/GSAP 加 Chrome 抽帧管线，
   HyperFrames 负责规则校验与动效约束。
