# 技术分享 · 顶部讲解位与章节进度条

## 整体判断

这是一条标准的「幻灯片 + 主播画中画」技术讲解片。画面不是靠频繁切镜制造节奏，而是靠一套**常驻 HUD 外壳**把观众固定在同一个阅读框架里：顶部章节进度条告诉观众「现在讲到哪」，左上讲解位告诉观众「这一页要理解什么」，右上主播画中画维持讲述者的存在感，底部字幕负责跟读。主画布换页，外壳不动。

参考片为 16:9（1280×720，30fps），前 60 秒共切 9 次，单镜停留 4–15 秒，切点跟着语义和章节走，不跟节拍走。

## 常驻 HUD 外壳

这是本风格最需要复刻的部分，四条水平结构从上到下固定：

1. **章节进度条**（贴画面上边缘，约占 26px）：`引言 | 1. 找到适合你的 Skill | 2. 把你的经验打包成 Skill | 3. 把多个 Skills 组合成工作流 | 4. 批量化定时化工作流 | 总结`。段与段之间用细竖线分隔。当前章节为亮白，切换瞬间出现浅色药丸底；其余章节压暗成灰。**全片常驻，B-roll 和全屏口播期间也不隐藏**，始终压在最上层。
2. **元信息行**：左侧是小号大写章节标签（`SKILL WORKFLOW · OPENING`、`SKILL WORKFLOW · 4 STAGES`），右侧是页码计数器（`01 / 33`、`02 / 33`），换页时递增。
3. **左上讲解位**：小号眉题 → 两行大字标题（衬线）→ 英文副标（`Find · Package · Orchestrate · Operate`）→ 一句灰色正文。**一页只放一个判断**，标题就是这段口播的结论，不重复字幕内容。
4. **右上主播画中画**：圆角矩形，约 260×160。幻灯片为主时固定挂右上；切到全屏口播或 B-roll 时让位。

底部另有两条：居中字幕药丸（深色圆角 + 白字，单行短句），以及左下角小号大写关键词序列、右下角日期水印（`— 2026.04 —`）。

## 主画布的几种页面

- **主张页**：大字判断句 + 英文副标 + 说明段，承担观点输出（如「Skill：把 AI 从聊天框带进真实工作流」）。
- **数字证据页**：把关键数字放到极大字号（`150天`、`9版`），背后铺密集的卡片墙或界面截图当证据。
- **流程信息图页**：编号圆形图标 `01–04` 横排，箭头连接；**当前步骤用发光圆角卡片包边，其余步骤压暗**，随解说逐项点亮。
- **关系图页**：两个圆角节点 + 箭头，表现「固定成一个动作 → 不必每次解释」这类因果。
- **图标墙页**：深色底铺 App 图标网格，说明兼容范围。
- **B-roll 插播**：圆角矩形画面居中，左右用同源画面做模糊铺底，避免黑边。
- **全屏口播**：直接切主播中景/近景，章节条和字幕继续压在最上层。

画面底色统一为近黑（约 `#0d0d0d`），正文与标题为白色，冷色只出现在图元点缀上，整体保持低饱和高对比。

## 节奏与动效

1. 换页不做花哨转场，基本是硬切或短促淡入，控制在 200–400ms。
2. 章节条只做高亮位移和药丸出现，不做位移动画。
3. 信息图形按解说顺序逐项点亮，是这一分钟里最有效的「内部变化」，用来解决长镜头容易发闷的问题。
4. 右侧中部有一枚小幅装饰贴纸做上下浮动，只提供节奏感，不承载信息。
5. 全程没有无意义的持续缩放。

## 可复用与不可复用

可复用：

- 常驻 HUD 外壳（章节条 + 页码 + 讲解位 + 字幕）这一整套层级关系。
- 「一页一个判断」的幻灯片编排方式，以及标题即结论的写法。
- 流程信息图逐项点亮、当前步骤发光包边的表达手法。
- 深色底 + 白色衬线大字 + 冷色点缀的配色策略。
- 顶部章节条在 B-roll 和全屏口播期间继续常驻的做法。

不可复用：

- 参考中的品牌名、人物头像、原始文案和未授权界面截图。
- `150天`、`9版` 这类具体数字；换主题必须换成可核实来源的数据。
- 参考里 `01 / 33` 这种页码密度，短内容需要按实际页数重算。

## 移植到竖屏时的注意点

参考为 16:9，顶部章节条在整幅宽度上并排 6 段中文，字号已经很小。竖屏直接缩放会导致章节名不可读，应改为：章节条保留顶部满宽但减少同时可见的段数（例如只显示当前段 + 前后各一段，其余折叠成圆点刻度），主播画中画从右上改为下方或顶部居右，讲解位下移到画面上三分之一。
