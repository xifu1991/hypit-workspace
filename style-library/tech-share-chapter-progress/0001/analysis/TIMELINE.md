# 时间轴与表达关系

以下时间来自豆包录音文件识别 2.0 的词级对齐（`reference/transcript.json`），画面节点按前 60 秒抽帧确认。

## 0.27–5.75 · 钩子：现场回放

口播：「几个月前，我到影视飓风分享了 Agent 加 skill 的工作流。那这几个月我们迭代了 9 个版本。」

画面为活动现场实拍回放，白色大号斜体 `Agent + Skill` 直接叠在实拍上；主播小窗压在**右下角**；底部字幕跟读。顶部章节条已经就位。这一段的作用是给资历背书，所以刻意不用演播室幻灯片。

## 6.31–7.0 · 数字证据页

口播：「今天就跟大家分享一下怎么用 skill 把 AI 从聊天框带到你自己的真实工作流。」

切到深色幻灯片，极大字号打出 `150天`、`9版`，背后铺密集卡片墙。只停一拍就换页，作用是给「迭代了 9 个版本」配证据。主播画中画此时从右下**移到右上**并固定下来，之后整段都保持在这个位置。

## 7.0–14.0 · 主张页

演播室正式开讲的第一页：眉题 `团队工作流 · AI AGENT`，两行大字标题「Skill：把 AI 从聊天框带进真实工作流」，下面接英文副标 `Find · Package · Orchestrate · Operate` 和一句灰色说明。这一页停留约 7 秒，是全片的题眼，字幕先走、画面后切。

## 14.0–27.0 · 四阶段路线图

口播：「我把 Agent 加 Skill 的使用分为了四个阶段。从找到适合你自己使用的 Skill 到把自己的经验打包成为 Skill 然后把 Skill 们组装成为适合团队使用的工作流，以及把 Skill 批量化、定时化，做成你的数字同事。」

这是全片最长的一个镜头，约 13 秒不加切。画面上半是结论句「我把 agent 加 skill 的使用分为四个阶段」，下半是四步信息图 `01–04` 横排。**这段长镜头完全靠步骤逐项点亮维持信息变化**：说到第几步，对应圆标和文字就变亮，最后一步用发光圆角卡片包住，配合字幕推进到「定时化做成你的数字同事」。

## 27.0–30.0 · 路线图收口与换章

口播：「而这就是今天这期视频会讲到的全部内容。」

先切全屏主播口播把目录收掉，再压成近黑页、只留一个正在放大的大标题。这是本章唯一一次黑场过渡，也是章节条上高亮推进的时机。

## 30.0–33.8 · 主张页回场

题眼页重新出现并把标题压到画面下方，作为从「目录」进入「正片」的交接点。

## 33.82–38.30 · 提问页

口播：「明明大家用的都是 Agent，为什么体验的差距那么大？我的答案很直接，那就是 Skill。」

先给全屏主播口播（中景），再切回幻灯片抛出问题句，用「提问 → 亮答案」的两拍完成章节开场。章节条在这一段明确亮到「1. 找到适合你的 Skill」。

## 38.30–47.62 · 定义页：关系图

口播：「Skill 的价值在于它把一类的操作流程固定成为了一个动作，这样我们不需要每次跟模型去解释，只需要让模型去执行这个 Skill 就可以了。」

页面用两个圆角节点加箭头画出一条因果：`固定成一个动作 → 不必每次解释`。字幕跟着口播走完整句，讲解位只留结论词，不再重复整段话。

## 48.10–50.02 · B-roll 插播

口播：「Hold on hold on，这里是后期的卡尔。」

插入一段圆角矩形画中画口播，左右用同源画面做模糊铺底。**顶部章节条和底部字幕在插播期间继续常驻**，观众不会丢失进度。

## 50.34–58.26 · 回到主播：兼容性说明

口播：「实际上，这些平时我们会用到的 agent 都兼容我今天讲的这套方法，而且不管是终端界面还是桌面端界面都能适用。」

切回全屏主播近景，随后进入深色图标墙页，用 App 图标网格把「都兼容」变成可见的证据，而不是只靠口播断言。

## 58.46–61.90 · 引例

口播：「所以我先给大家看一个真实的例子，这里我准备了一个提。」

页面切到带播放按钮的界面截图，作为下一段实操演示的入口，章节条保持不跳。
