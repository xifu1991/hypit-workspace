# 阿玛尼玉龙茶香 · 口播种草

## 整体判断

这是一条以真人口播建立信任、用产品和香调画面完成种草的竖屏产品介绍。主播完整露脸承担开场、转折和结论；中段大量使用人物抠像、产品近景、香调原料、人物氛围和生活方式画面，让视觉从“谁在说”转向“为什么值得买”。

## 核心剪辑语言

1. 完整人物镜头主要用于开场、承接和结尾，中段不持续占满画面。
2. 主体经常以抠像小人形式位于画面下方或侧边，后方铺满产品、香调或氛围画面。
3. 视觉按语义切换，而不是机械定时；典型画面停留约 2–4 秒。
4. 底部跟读字幕负责阅读，大号白/黄色花字负责卖点和结论。
5. 产品证据画面占比高于完整露脸画面，B-roll 承担想象和使用场景。
6. 开头和结尾回到完整人物画面，中段以产品图、氛围图和原料图维持变化。

## 开场

第一句先提出香水使用频率和百搭价值，随后快速拿出产品并介绍适用场景。开场有明确钩子，主播和产品在同一直播空间内建立可信关系。

## 中段展开

中段按香调、使用场景和产品价值拆分语义单元。产品出现时切换为产品近景、原材料、生活氛围或模特画面；主播常以抠像小人继续讲解。黄色或白色花字落在卖点关键词和结论上，底部字幕保持口播可读性。

## 结尾

最后回到完整人物画面，用总结和建议收束内容，保留自然行动引导，不突然截断。

## 可复用与不可复用

可复用：

- 口播为轴、语义切画面的结构。
- 完整人物与产品/氛围画面的比例和节奏。
- 两级文字：底部跟读字幕 + 独立卖点花字。
- 开头与结尾回到完整人物的包夹结构。
- 产品持握、香调原料和生活方式画面的交替。

不可复用：

- 阿玛尼品牌、具体文案和第三方产品图片不能原样迁移。
- 没有授权或无法确认来源的素材不能伪装成新产品的真实证据。
- 旧工程的黑底圆窗和固定图片模板不能当作本风格本身。
