# AI工具测评 · 屏幕证据拆解

## 整体判断

这是一条 18 秒竖屏产品讲解，核心不是展示“AI 剪辑有多强”，而是用真实截图、录屏、时间轴和失败案例证明“全自动剪辑不值得买”。口播负责提出判断，屏幕证据负责把判断落到画面；真人主播只在前 5 秒短暂占据主画面，随后缩成圆角小窗，成为反应层和连续性锚点。

## 核心剪辑语言

1. 屏幕证据优先于人物表演。搜索结果、宣传页、导出成片、失败画面和音轨波形是主画面，主播经常只保留右下或底部小窗。
2. 关键判断使用红色证据化元素。红章“割韭菜”、红圈、红色大数字、红色结论条和时间轴标记线承担“抓错”的视觉职责，不是普通装饰花字。
3. 证据链标签逐步出现。`真买了`、`真用了`、`才发现` 用绿色勾选和递进位置把“实际体验”变成一个可核对的流程。
4. 问题卡承担段落转场。米白画布上的 `问题来了` 和 `为啥 AI 做不了自动化剪辑？` 把产品测评从现象切换到原因分析。
5. 编号卡重复同一套语法。`01` 始终位于左上，正文只换核心矛盾：`它不懂人的审美`、`字幕挡住画面主体`、`大字该何时进？又该何时出？`。
6. 最后用时间轴取证。画面时间 12.4 秒、口播时间 13.6 秒、绿色音轨波形和红绿标记被并排呈现，红章 `早了 1.2 秒` 负责落结论。

## 时间结构

- `0.42–4.94 秒`：开头判断，全屏主播先建立“我在说大实话”的可信感，再切到 B 站搜索结果和 `视频 99+ / 专栏 99+`，红章 `割韭菜` 完成第一击。
- `5.14–8.76 秒`：体验证据，`真买了 / 真用了 / 才发现` 逐项出现，卖家秀宣传页和买家秀导出成片形成正面对照，并用 `字压脸`、`字压嘴`、`脸糊掉`、`大黑边` 标注失败点。
- `8.76–11.84 秒`：问题卡，画面从证据回到问题，`问题来了` 和黄色高亮限定 `自动化剪辑`，让观众进入原因拆解。
- `11.84–15.36 秒`：编号拆解，`01` 卡逐项替换，先讲审美，再讲字幕遮挡，最后把问题收窄到“大字何时进、何时出”。
- `15.36–18.04 秒`：时间轴取证，波形、画面帧和口播时间对齐，红绿标记说明画面比口播早了 1.2 秒。

## 与现有拆解风格的区别

1. 不同于 `full-frame-presenter`：全屏口播只用于开头信任建立，很快被屏幕证据取代。
2. 不同于 `black-rectangle-pip-title` 和 `black-circle-pip-scene-tags`：这里没有黑底标签板，主播窗是米白画布上的圆角方窗。
3. 不同于 `product-hero-speaker-pip`：主画面不是产品特写，而是软件界面、搜索结果、宣传页、导出结果和音轨波形。
4. 不同于 `product-follow-label`：标注不跟随产品运动，而是圈出证据位置、标明失败原因、比较画面与口播时间。
5. 不同于其他纯种草型产品讲解：这条视频的证据链是“论点 -> 反例 -> 问题 -> 拆解 -> 时间轴验证 -> 结论”，带有明显的测评和打假叙事。

## 可复用部分

- 真人口播建立信任，随后把主播缩成小窗，让真实界面成为主画面。
- 用 `真买了 / 真用了 / 才发现` 这类证据链标签把主观测评变成可核对过程。
- 用红章、红圈、编号卡和错误标注承担关键判断，不用装饰性花字填满画面。
- 用问题卡切换叙事阶段，用编号卡连续拆解同一问题的多个原因。
- 用时间轴、波形和画面对照做最终验证，再以红色结论条收束。

## 不可复用与限制

- 不复制原视频中的人物、搜索内容、软件截图、宣传文案、具体数据和品牌信息。
- 替换素材时必须保证截图、录屏和时间轴来自真实可核实的产品，不能伪造成证据。
- 9:16 画面中的屏幕文字必须保持可读；如果原始录屏太小，应单独重排为局部放大，而不是直接缩到看不清。
- 该风格依赖主播小窗、干净画布和屏幕证据。缺少可授权界面素材时，只能复用结构和节奏，不能自动生成假截图。
